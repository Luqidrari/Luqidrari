- 📊 **Complex financial data workflows** — multi-year submissions, autosave, draft/submission states, automated PDF & Excel report generation
- 🔐 **Auth & access systems** — OTP authentication, JWT, role-based access control (RBAC), public token-based forms

- 🏭 **Production tracking system** for quality control with automated daily/monthly Excel & CSV reports

- 🎓 **Training platform** with automated certificate generation and email distribution
